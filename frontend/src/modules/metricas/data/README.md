# Datos geográficos

`huanuco_provincias.json` contiene los límites provinciales de Huánuco en GeoJSON
(WGS84), simplificados y con coordenadas redondeadas a 5 decimales para uso web.

- Fuente: [juaneladio/peru-geojson](https://github.com/juaneladio/peru-geojson)
  (`peru_provincial_simple.geojson`, MPL-2.0).
- Datos originales: Geoservidor MINAM / GEOIDEP, límite provincial INEI-2007.
- Solo se conservaron las 11 provincias de Huánuco y las propiedades
  `id` (ubigeo) y `nombre`.
